# Skill: Vowvel Invitation Curator

Curate bespoke wedding and engagement invitation experiences across Vowvel's five signature artistic themes.

## Usage

Use this skill when helping a couple or event host select, customize, or preview an invitation.

## Signature Themes

1. **Conservatory**: Glasshouse botanical romance, botanical ivory, hand-pressed gold foil, organic flora.
2. **Gulmohar**: Royal crimson, marigold arches, grand heritage festivities, Indian palace architecture.
3. **After Hours**: Black-tie noir, chandeliers, midnight jazz salon, modern champagne gala.
4. **Sunday Edit**: Warm linen, relaxed editorial typography, intimate countryside weekend.
5. **Azure**: Mediterranean cliffside, cobalt tiles, sea spray and bougainvillea.

## Actions

- **List Themes**: Retrieve visual aesthetics, color palettes, and envelope styles.
- **Generate Draft**: Assemble couple names, wedding date, venue maps, schedules, and dress codes into a validated invitation JSON structure.
- **Preview Demo**: Link to live guest interactive demo at `https://vowvel.com/#/preview/{theme}`.
